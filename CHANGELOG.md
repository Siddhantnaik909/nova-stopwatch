# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2025-05-26

### Added
- ⏱️ **Stopwatch Mode** - Classic time tracking with centisecond precision
- ⏲️ **Timer Mode** - Countdown timer with preset configurations and adjustable durations
- 🍅 **Pomodoro Mode** - Work/break cycle timer with customizable intervals
- 🎯 **Focus Mode** - Fullscreen immersive timing experience
- 📊 **Lap Tracking** - Record and view lap times with statistics
- 🔔 **Audio Alarm** - Visual and audio notifications when timer completes
- ⌨️ **Keyboard Shortcuts** - Full keyboard navigation support
- 🎨 **6 Color Themes** - Cyber Gold, Neon Blue, Matrix Green, Crimson Red, Vaporwave, Midnight Eclipse
- 📱 **Responsive Design** - Works seamlessly on desktop, tablet, and mobile
- 💾 **Session History** - Save and manage session data in local storage
- 📤 **Data Export** - CSV and JSON export formats
- 🖱️ **Mini Widget** - Draggable floating stopwatch widget
- ♿ **Full Accessibility** - WCAG 2.1 compliant with ARIA support
- 🔇 **Sound Settings** - Customizable sound effects and ticking

### Technical
- Zero external dependencies (pure vanilla JavaScript)
- ES2021+ features
- CSS custom properties and grid/flexbox layout
- Semantic HTML5 markup
- LocalStorage persistence
- RequestAnimationFrame optimization
